# @aegispath/ui-art

Pure SVG illustrations, mascot assets, and interactive security diagrams.

## Purpose
Provides self-contained SVG components for:
- Mascot "Chop" across 4 distinct emotional states (`wave`, `idle`, `guard`, `block`, `paused`).
- Header doodles (clouds, 4-point sparkles, currency coins, student paper plane).
- Interactive 3-Ring Radial Attack Map with live pulse animation.
